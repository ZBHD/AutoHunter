# 任务列表状态筛选设计

## 目标

在任务列表页面增加状态筛选，让用户快速查看运行中、已暂停或已停止的任务。

## 交互

- 筛选项按“全部 / 运行中 / 已暂停 / 已停止”的顺序展示。
- 默认选择“全部”，展示所有任务。
- 筛选为单选，切换后立即更新当前列表。
- 每个筛选项展示对应任务数量。
- 当前筛选没有匹配任务时，展示筛选空态；任务总数为零时继续展示原有空态。

## 状态归类

- “运行中”匹配 `running`。
- “已暂停”匹配 `paused`、`idle`、`created`。
- “已停止”匹配 `stopped`。
- 任务卡片继续展示任务自身的原始状态标签，不修改后端状态和接口。

## 实现范围

- 在 `TasksView.vue` 内维护当前筛选值，并通过计算属性完成客户端筛选与数量统计。
- 在任务列表标题下方增加紧凑的状态筛选控件。
- 复用现有视觉变量，补充桌面端和移动端样式。
- 增加前端测试，覆盖筛选顺序、状态归类、渲染数据源和空态。

## 非目标

- 不修改任务列表 API。
- 不修改任务状态机或任务卡片状态文案。
- 不持久化用户上次选择的筛选项。
